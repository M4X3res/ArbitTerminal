## 🔥 НОВЫЕ ИСПРАВЛЕНИЯ (сегодня)

### 1. ✅ Убрано ограничение MAX_ORDERS_PER_COIN

**Проблема:** Было ограничение на 1 ордер на монету, что мешало адаптивной стратегии открывать несколько позиций на разных биржах.

**Решение:**
- Удален параметр `MAX_ORDERS_PER_COIN = 1` из `config.py`
- Добавлен параметр `MAX_POSITIONS_PER_EXCHANGE = 3`
- Теперь система контролирует количество позиций **по биржам**, а не по монетам
- Можно открывать несколько позиций на одну монету, если они на разных биржах

**Изменения в файлах:**

#### config.py:
```python
# Было:
MAX_ORDERS_PER_COIN = 1

# Стало:
MAX_POSITIONS_PER_EXCHANGE = 3  # Максимум 3 позиции на одной бирже
```

#### risk_manager.py:
```python
# Было:
self.orders_per_coin = {}

# Стало:
self.positions_per_exchange = {}  # Подсчет по биржам

# Проверка изменена с:
coin_orders = self.orders_per_coin.get(opportunity.symbol, 0)
if coin_orders >= MAX_ORDERS_PER_COIN:
    return {"approved": False, ...}

# На:
long_positions = self.positions_per_exchange.get(opportunity.exchange_long, 0)
short_positions = self.positions_per_exchange.get(opportunity.exchange_short, 0)

if long_positions >= MAX_POSITIONS_PER_EXCHANGE:
    return {"approved": False, ...}
if short_positions >= MAX_POSITIONS_PER_EXCHANGE:
    return {"approved": False, ...}
```

#### Обновлены методы register/unregister:
```python
# register_position теперь принимает биржи:
def register_position(self, symbol: str, exchange_long: str, exchange_short: str):
    self.open_positions.append(symbol)
    self.positions_per_exchange[exchange_long] = self.positions_per_exchange.get(exchange_long, 0) + 1
    self.positions_per_exchange[exchange_short] = self.positions_per_exchange.get(exchange_short, 0) + 1

# unregister_position обновлен аналогично:
def unregister_position(self, symbol: str, exchange_long: str = None, exchange_short: str = None):
    # Уменьшает счетчики для обеих бирж
```

## 📊 Что изменилось в логике работы

### Было:
```
Проверка: сколько ордеров на монету BTC? 
→ Если >= 1, блокировать новый ордер
→ Можно открыть только ОДНУ позицию на BTC, даже если спред на разных биржах
```

### Стало:
```
Проверка 1: сколько всего открытых позиций?
→ Если >= 3, блокировать (MAX_OPEN_POSITIONS)

Проверка 2: сколько позиций на бирже MEXC?
→ Если >= 3, блокировать (MAX_POSITIONS_PER_EXCHANGE)

Проверка 3: сколько позиций на бирже Gate?
→ Если >= 3, блокировать (MAX_POSITIONS_PER_EXCHANGE)

✅ Можно открыть несколько позиций на BTC, если они на разных биржах!
```

### Пример:
Теперь **возможно** одновременно:
- BTC: MEXC ↔ Gate (Long на MEXC, Short на Gate)
- BTC: Bybit ↔ AsterDEX (Long на Bybit, Short на AsterDEX)
- ETH: MEXC ↔ Bybit (Long на MEXC, Short на Bybit)

Все три позиции открыты, но ни на одной бирже нет перегрузки (на каждой по 2 позиции).
