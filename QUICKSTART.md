# Запуск системы без API ключей

## Быстрый старт

Система может работать в режиме мониторинга **без API ключей** - будет отслеживать арбитражные возможности, но не совершать реальные сделки.

### 1. Установка зависимостей

```bash
pip install aiohttp websockets
```

### 2. Запуск демо-режима

```bash
.venv\Scripts\python.exe main.py
```

Система будет:
- ✅ Подключаться к WebSocket всех 4 бирж
- ✅ Получать реальные цены и funding rates
- ✅ Искать арбитражные возможности
- ✅ Проверять риски
- ❌ НЕ будет совершать реальные сделки (нет API ключей)

### 4. Тестирование торговых методов (с API ключами)

Если у вас есть API ключи, можете протестировать торговые функции:

```bash
.venv\Scripts\python.exe test_trading_api.py
```

**ВАЖНО:** Сначала замените API ключи в файле!

## Архитектура

```
main.py                    # Главный orchestrator
├── MarketDataEngine       # WebSocket потоки данных
├── ArbitrageEngine        # Поиск возможностей
├── TradingEngine          # Исполнение ордеров (требует API ключи)
└── RiskManager            # Проверка рисков
```

## Что дальше?

### С API ключами:
1. Скопируйте `.env.example` в `.env`
2. Заполните API ключи
3. Запустите систему в режиме реальной торговли

### Без API ключей:
- Система работает как мониторинг арбитража в реальном времени
- Можно анализировать частоту и размер возможностей
- Оценить потенциальную прибыльность стратегии

## Настройка

Параметры в `config.py`:
- `OPEN_THRESHOLD` - минимальный спред для открытия (%)
- `MAX_POSITION_SIZE` - максимальный размер позиции (USD)
- `MAX_OPEN_POSITIONS` - максимум одновременных позиций
